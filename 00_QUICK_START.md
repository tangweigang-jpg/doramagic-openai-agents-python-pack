# Quick Start

## Outcome

give AI builders a first durable OpenAI Agents workflow with tool boundaries, handoff checks, eval prompts, and recovery rules for multi-agent drift

## Two-Minute Path

1. Read `AGENTS.md`.
2. Copy the relevant host instruction into your AI coding host.
3. Run `06_EVALS/smoke_check.md`.
4. If the check fails, open `03_PITFALL_LOG.md`.

## Official Upstream Entry

```text
pip install openai-agents
```

Source: https://github.com/openai/openai-agents-python
